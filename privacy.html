1) Données collectées

Nous collectons uniquement les informations que vous fournissez via les formulaires du site (nom, entreprise, e-mail, téléphone, message, informations RFQ).

Ces données sont utilisées pour répondre à vos demandes (devis, documents, partenariats), assurer le suivi, et améliorer la qualité de service.

3) Traitement via un service tiers

Les formulaires peuvent être traités via un service tiers (ex : FormSubmit) afin de transmettre votre message par e-mail à ORION FISH.
